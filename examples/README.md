## Running the Examples

Follow these steps to set up and run the example scripts.

### 1. Install the Library

First, install the `usos-bridge` library using pip.

### 2. Set Up Environment Variables

1.  Copy the template file:

```bash
cp .env.template .env
```

2.  Open the newly created `.env` file and fill in your credentials.

### 3. Install Example Dependencies

The examples may require additional packages. Install them from the `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### 4. Run an Example

You can now run any of the example scripts. For instance, to run the user fetching example:

```bash
python user_fetch.py
```
